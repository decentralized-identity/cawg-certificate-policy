[[android-key-attestation]]
=== Android key attestation

Android key attestation can be used for validating the security attributes of a <<subscriber,subscriber>>’s CAWG claim signing key, validating the identity and integrity of the instance of the generator product requesting certificates, and validating the integrity of the Android platform on which the application is running.
