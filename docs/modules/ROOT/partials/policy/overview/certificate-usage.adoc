[[certificate-usage]]
=== Certificate usage

[[intended-use]]
==== Intended use

<<certificate,Certificates>> issued under this <<certificate-policy,CP>> are to be used exclusively by the individuals and organizations named as the subjects of the certificates to digitally sign <<cawg-identity-assertion,CAWG identity assertions>>.

[[prohibited-use]]
==== Prohibited use

Any use of certificates issued under this policy outside of the <<cawg-identity-assertion,CAWG identity assertion>> specification or the <<cawg-conformance-program,CAWG conformance program>> is strictly prohibited.
