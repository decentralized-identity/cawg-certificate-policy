[[identification-and-authentication-for-re-key-requests]]
=== Identification and authentication for re-key requests

<<certificate,Certificate>> re-key is not permitted (see <<certificate-re-key>>).
A request for a <<certificate,certificate>> for a new <<key-pair,key pair>> MUST be treated as an application for a new <<certificate,certificate>>, and the <<certification-authority,CA>> MUST perform the identity validation processes defined in <<identification-and-authentication-for-certificate-issuance-and-certificate-renewal>>.
