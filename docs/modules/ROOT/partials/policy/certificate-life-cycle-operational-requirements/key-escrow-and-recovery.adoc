[[key-escrow-and-recovery]]
=== Key escrow and recovery

<<subscriber,Subscriber>> <<private-key,private keys>> MUST NOT be escrowed, archived, or backed up by the <<certification-authority,CA>>, any <<registration-authority,RA>>, or any <<delegated-third-party,delegated third party>>.
Key recovery is not supported.

A <<subscriber,subscriber>> signature is evidence that the <<subscriber,subscriber>> made it only if no other party holds a copy of the <<private-key,private key>>.
