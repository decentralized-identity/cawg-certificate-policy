[[certificate-re-key]]
=== Certificate re-key

<<certificate,Certificate>> re-key is not permitted.
A <<subscriber,subscriber>> that needs a <<certificate,certificate>> for a new <<key-pair,key pair>> MUST apply for a new <<certificate,certificate>>, and the <<certification-authority,CA>> MUST perform the identity validation processes defined in <<identification-and-authentication-for-certificate-issuance-and-certificate-renewal>>.
