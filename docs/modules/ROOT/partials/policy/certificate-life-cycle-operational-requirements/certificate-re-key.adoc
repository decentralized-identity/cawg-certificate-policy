[[certificate-re-key]]
=== Certificate re-key

All requests for subscriber certificate re-key shall be treated identical to applications for new certificates, and the <<certification-authority,CA>> MUST perform the same identity validation processes as defined in <<identification-and-authentication-for-certificate-issuance-and-certificate-renewal>>.
